# Вставка подписей в PDF (GUI)

Скрипт `pdf_signature_gui.py` — приложение с графическим интерфейсом (tkinter),
которое вставляет PNG-подписи двух подписантов в указанные страницы PDF-файла
и сохраняет результат обратно в исходный файл (без создания резервных копий).

## Установка

Требуется Python 3.8+ (tkinter входит в стандартную поставку CPython).

```bash
pip install PyMuPDF
```

> Если у вас Linux и tkinter отсутствует системно: `sudo apt install python3-tk`.

## Запуск

```bash
python pdf_signature_gui.py
```

## Использование

1. Нажмите **«Выбрать PDF файл»** и укажите обрабатываемый документ.
   Сразу после выбора автоматически запускается **автоопределение ячеек
   штампа**: границы ГОСТ-штампа ищутся по ключевым словам («Разработал»,
   «Проверил», «ГИП», «Н.контр.», «Разраб», «Чемыхин», «Лисицын»)
   через `page.search_for()`, а целевые ячейки вычисляются как относительные
   доли (0.0–1.0) от границ штампа (`CELLS_TEMPLATE`). Координаты найденных
   Rect-объектов выводятся в журнал. Если штамп не распознан — появляется
   сообщение «Штамп не распознан… Укажите координаты вручную или проверьте
   PDF» и включается fallback-режим.
2. В поле **«Страницы для обработки»** введите список страниц, например:
   - `1,10-16,21` — страницы 1, 10–16 и 21;
   - `5` — только пятая страница;
   - **оставьте пустым** — будут обработаны ВСЕ страницы документа
     (в режиме автоопределения это не обязательно: штампы распознаются
     сами, указание страниц доступно по желанию).
   Нумерация — с единицы, как в обычном просмотрщике PDF.
3. Укажите папку с PNG-подписями **Подписанта 1** и папку с PNG-подписями
   **Подписанта 2** (в каждой папке может быть несколько PNG — случайный PNG
   выбирается заново для каждой вставки на каждой странице, а не один раз
   на весь документ).
4. При необходимости включите чекбокс **«Ручной режим»** — вставка по
   фиксированным координатам страницы без автопоиска штампа (fallback).
5. Нажмите **«Обработать»**. Ход работы виден в окне «Журнал»: для каждой
   страницы выводится статус распознавания штампа, имена ячеек, прямоугольники
   вставки и выбранные файлы подписей. Все этапы поиска также логируются
   через модуль `logging`.
6. По завершении появится сообщение **«Готово!»**; исходный PDF будет
   перезаписан обработанной версией (резервные копии не создаются).

## Автоопределение ячеек штампа (настраивается константами в начале скрипта)

Ячейки задаются как доли от границ найденного штампа (`CELLS_TEMPLATE`):

```python
CELLS_TEMPLATE = {
    "signature": {"rel_x": 0.55, "rel_y": 0.15, "rel_w": 0.15, "rel_h": 0.12},
    "stamp":     {"rel_x": 0.72, "rel_y": 0.15, "rel_w": 0.12, "rel_h": 0.12},
    "date":      {"rel_x": 0.72, "rel_y": 0.27, "rel_w": 0.12, "rel_h": 0.12},
}
```

Порядок вставки 4 подписей по ячейкам (`CELL_ORDER`):
места №1/№3 → Подписант 1, места №2/№4 → Подписант 2.
Такой подход работает со штампами любого размера и положения на листе.

## Ручной режим (fallback)

Размер каждой подписи: **8 × 16 мм** (≈ 22.68 × 45.35 пунктов, `MM_TO_PT = 2.83465`).
Все подписи размещены в 100 пунктах от правого края страницы.

| Место | Подписант   | Отступ от нижнего края |
|-------|-------------|------------------------|
| №1    | Подписант 1 | 7 pt                   |
| №2    | Подписант 2 | 14 pt                  |
| №3    | Подписант 2 | 21 pt                  |
| №4    | Подписант 1 | 28 pt                  |

Координаты считаются от верхнего левого угла страницы:

```
x = ширина_страницы − 100 − ширина_подписи_pt
y = высота_страницы − отступ_снизу_pt − высота_подписи_pt
```

## Проверки и обработка ошибок

Перед обработкой проверяются: заполненность всех полей, существование PDF,
формат строки страниц (`ValueError` при `"abc"`, `"10-5"` и т.п.), наличие
PNG-файлов в обеих папках, существование указанных страниц в PDF.
Все ошибки выводятся через диалог `messagebox.showerror` и дублируются в журнале.
